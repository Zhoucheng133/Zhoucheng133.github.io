## 安装

```bash
# 对于macOS
# v2
curl -fsSL https://opencode.ai/v2/install | bash
# v1
curl -fsSL https://opencode.ai/install | bash

# 对于Windows
npm install -g @opencode/cli
```

## 配置

### 设置非常驻模式
用来启用代理模式，防止出现无法应用代理的情况

注意仅对`v2`有效，`v1`不会常驻后台

```bash
opencode service set disabled true
```
